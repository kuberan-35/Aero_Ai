# Drone ETA Prediction Project

## Overview
This project predicts drone delivery ETA using Machine Learning (Random Forest).
A Streamlit dashboard interface allows real-time predictions and dataset visualization.

## Files Included
- requirements.txt – Dependencies  
- README.md – Project documentation  
- project_report.pdf – Project summary (to be generated in step 3)

## How To Run
```bash
pip install -r requirements.txt
streamlit Aaro_ai.py
```
